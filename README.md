# StudentAuction

A student auction website developed for Semester Project 2.

StudentAuction will allow visitors to browse and search auction listings. Registered users with "@stud.noroff.no" email will be able to create listings, manage their profile and place bids with virtual credits.

## Project status

The initial project setup and deployment are complete.
The rest is under development.

## Getting started

### Prerequisites

- Node.js 24
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/remiytter/semester-project2.git
```

Open the project folder:

```bash
cd semester-project2
```

Install dependencies:

```bash
npm ci
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

## Production build

Build the website:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Deployment

The website is automatically built and deployed to Github pages through GitHub actions when changes are pushed to main.
